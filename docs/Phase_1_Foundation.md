# Phase 1: Foundation — Student, Batch & Fee Core

**Duration:** 2–3 weeks

## Goal
Replace the register/Excel system immediately for instant relief.

## Features
- Student & parent profile management
- Batch/course creation and assignment
- Fee structure setup, installment tracking, receipt generation
- Basic admin dashboard (total students, pending fees, batch strength)

## Wow Factor
A live dashboard the owner can check from his phone instead of asking staff for updates.
