# Phase 2: Attendance + WhatsApp Automation

**Duration:** 1–2 weeks

## Goal
Deliver the "magic" feature that drives referrals.

## Features
- Daily attendance marking (simple teacher-side UI)
- Auto WhatsApp/SMS alerts to parents: absence notices, fee due reminders
- Payment link sharing via WhatsApp (UPI/Razorpay integration)

## Wow Factor
Parents start messaging the owner, "Wow, you guys are so organized now" — this is what turns him into your best referral source.
