# Phase 3: Academics — Tests, Performance & Reports

**Duration:** 2–3 weeks

## Goal
Bring visible academic value to parents and the owner.

## Features
- Test scheduling and marks entry
- Auto-generated performance report cards (PDF, shareable on WhatsApp)
- Rank lists, progress graphs per student
- Batch-wise performance comparison for the owner

## Wow Factor
Parents receive a clean, professional progress report that looks like it's from a premium ed-tech company.
